## 怎么用这张账

下一轮复审请**从这张表的 `断言` 列开始抽验**：随便挑三条绑了断言的，把它们指向的断言
改坏（或在本地把断言删掉），跑 `npm test` 看是否变红。**改坏了却全绿，就说明这条「已修」
是纸上的。** 这比重新读一遍材料省时间，也正好压住这个项目栽过两次的那类病
（0.9.17 / 0.9.18 两个套件漏登记、126 条断言从没跑过，而两版 CHANGELOG 都写着「全绿」）。
