# 潮汐任务失败处理

失败分三类，处理方式不同：

- 可重试：瞬时错误，按退避重试，最多三次。
- 不可重试：输入错误，直接标失败。
- 跳过：错过时间窗，不重试也不标失败。

第三类最容易被误当成失败，报表里那部分数字其实是「没跑」。

把三类分开之后，成功率这个指标才有意义：跳到一类会同时抬高分母与分子，
让结果看起来一切正常。报表里现在把它们分成三行并列显示。
三类的比例要分开看趋势：跳过变多，通常意味着窗口太窄，而不是任务质量变差。
重试上限写在任务定义里，而不是调度器的全局配置里，这样每个任务可以不同。
改了上限要同步改报表里的分档，否则两类数字对不上；分档与定义不一致时，先信定义。
