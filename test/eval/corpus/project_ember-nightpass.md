# 灰烬笔记（续）

到了设定时刻会自动跑一遍，把重复的条目并到一处，顺手丢掉几类明显过期的内容。
第二天打开时，只会看到最相关的那几条，其余的都留在馆里等你自己去翻。

这个过程不进主流程，可以随时叫停，也可以在叫停之前先看一眼它打算做什么。
我保留的是「先看一眼再动手」这一步：自动动作最容易出问题的地方不是逻辑，
而是它在你没注意的时候动了什么。

并条目的规则只处理明显重复的情况，宁可漏并也不要错并。
丢掉的那几类内容会先记一份清单，清单本身不参与后续的整理。
叫停的入口放在执行之前，而不是执行中间，免得半途停在一个谁也解释不了的状态。
清单保留最近几次，更早的合并成一条摘要，避免它自己变成新的噪音。
