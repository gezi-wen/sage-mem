# 明灯快捷键

- 切换主题：`Ctrl+Alt+T`
- 打开星图：`Ctrl+Alt+S`
- 收起侧栏：`Ctrl+Alt+B`

三组都在全局生效，输入框内不拦截。

冲突时的优先级是「后注册的赢」，插件注册的快捷键会覆盖内置的那一组。
想临时停用某一组，可以在设置里把它清空，而不是改键位——改键位会影响已有的肌肉记忆。
快捷键只在窗口获得焦点时生效，托盘菜单里按不出来，这一点新手常问。
三组之外还有一组留给插件，名字不与内置的冲突，设置页里单独分区显示。
设置页里的改动立刻生效，不需要重启；但已打开的窗口要重新聚焦才会重新绑定。
这一条没写进面板提示，是使用反馈里被问得最多的一句。
