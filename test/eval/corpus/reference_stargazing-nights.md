# 观星记录

新月前后各三天最合适，满月那一周基本不用出门。
海拔比纬度重要，哪怕只高两百米，水汽也少一截。
冬季看猎户最省事，夏季要等银河升到天顶。

出门前看云量，别只看晴天预报。
带一张纸质星图比手机可靠，低温下手机掉电很快。
同一片天空在城郊与山里完全是两回事，先看光污染再定地点。
出发前一小时再看一次云量，预报的滞后在山里尤其明显；
风比温度更影响体验，背风的位置能让同一片天看起来清楚很多。
初次出门不必追深空目标，先把几个亮星座认熟，收获比硬找暗目标大。
月亮的位置比月相更影响观感，满月前后它整夜都在天上，视野里很难避开。
计划时先查月出月落，再查云量，顺序反了容易白跑一趟；夏天还要带上防蚊的东西。
