# Cobalt 调用配额

本节为 2026-09 修订，覆盖此前的数值，旧值一律作废。

每月调用上限是 200 万次，按自然月重置，月初的用量不计入上月。
突发上限是每分钟 9000 次，超过突发上限的请求会被削峰到下一分钟，不直接拒绝。

配额按租户单独计算，不跨租户共享；租户合并时两边的配额简单相加，不重新核定。
超出每月上限之后接口返回 429，并停止计费，直到下个月重置。

配额变更在每个自然月一号统一生效，月中提交的调整排到下个月。
临时提额只对当次调用有效，不写入配额记录。
配额记录按月归档，归档之后只能查不能改。

配额的读写走同一个接口，调整配额与查询用量都落在同一份记录上。
每月上限是硬限制，改它要同时改计费侧的档位表，否则账单与配额对不上。
