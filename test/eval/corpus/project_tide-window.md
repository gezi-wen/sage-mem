# 潮汐笔记

默认时段是 02:30 到 04:00，跨越夏令时切换的那一天会缩短一小时。
这段窗口与外部的备份任务重叠，重叠时备份优先，我们让出前二十分钟。
幂等键在错过后仍然保留，所以补跑不会产生重复结果，但我们仍然不补跑。
窗口内没跑完的任务会被标记为超时，而不是失败，这个区别在统计报表里很重要。

窗口的宽度是照着最慢一次运行的两倍定的，留出重试的余地。
把窗口收窄看起来能省资源，实际会让任务频繁落在超时那一档。
让出前二十分钟是硬约定，改窗口之前先确认备份那边的时段没有变。
窗口的起止时间在配置里写死，日历视图上的展示只是读它，不参与计算。
改完之后看一眼错过的任务有没有被标成跳过，那是最容易被漏掉的一步。
