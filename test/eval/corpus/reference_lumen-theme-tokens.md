# 明灯主题变量

- `--lm-bg`：面板底色
- `--lm-fg`：正文颜色
- `--lm-accent`：强调色
- `--lm-border`：分隔线颜色
- `--lm-shadow`：浮层投影

浅色档只用前四个，深色档五个都用。
新增变量必须同时在两个档位里给值，否则面板会回落到默认色。

回落到默认色不会报错，只会让两个档位看起来「差不多」。
排查主题问题时先确认变量在两个档位都存在，再看取值是否合理。
变量的命名前缀是固定的，插件自己的变量用另一套前缀，避免互相覆盖。
改完两个档位都要各看一遍，只在一个档位里调，另一个档位的问题会一直藏着。
新增变量先在浅色档里调，深色档的颜色通常由它推导，反过来做要来回改好几轮。
