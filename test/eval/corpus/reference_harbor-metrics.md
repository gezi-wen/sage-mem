# 港口调度器指标

- `queue_depth`：当前队列长度
- `task_state`：任务状态分布
- `retry_count`：重试次数
- `reject_total`：被拒总数

前两项每小时采样一次，后两项是累计值。
累计值要取差分才有意义，直接看总量只会看到一条向上的直线。

指标之间的关系比单个指标有用：队列长度下降而重试上升，说明吞吐没有真的恢复。
把这类组合写进看板，比多加几个指标更能减少误判。
采样频率也要写清楚：累计值可以做差分，采样值只能看趋势，
把两类混在一张图里，图的形状会随采样间隔变化，结论也跟着变。
看板里的时间范围默认是一天，跨天对比要手动调，否则会得出相反的结论。
