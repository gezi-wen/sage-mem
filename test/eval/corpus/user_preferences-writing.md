# 写作偏好

- 始终中文，术语第一次出现时给出中文与原文。
- 短句为主，一段一个意思。
- 不用 emoji，不用网络流行语。
- 引用代码行号时写成「文件:行号」。
- 重要的事放开头，补充信息放后头。

解释概念时用类比，不要用术语解释术语。不确定的事直接说不确定，
不要用「可能」「大概」把话说圆。汇报时先给结论，再给依据，最后给代价。
推荐任何东西都要把代价摆出来，只推荐一个选项等于没推荐。
不确定的事直接说不确定，然后去查，查完再回答，不要先给一个模糊的版本再补。
长内容可以分点，但每一点都要能独立读懂，不能靠上一点的下文才成立。
引用外部结论时给出处，方便回头核对；报告里不放没有结论的数据。
