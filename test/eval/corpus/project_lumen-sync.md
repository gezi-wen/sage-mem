# 明灯同步冲突

冲突只在两个客户端同时改同一条时出现。

- 正文按字段合并，标题冲突时保留较新的一条。
- 没网时改动进本地队列，恢复后按时间顺序重放。
- 重放失败的条目留在冲突区，不自动丢弃。

自动合并从不删除内容，只会把两边并起来。

按字段合并的前提是每个字段可以独立判断新旧，所以带嵌套结构的字段整体比较。
标题冲突保留较新的一条，是因为标题是给人看的入口，两边都留会让人不知道该点哪个。
冲突区的条目一直保留到人工处理，宁可留得多，也不要自动丢掉判不准的内容。
冲突区可以按条目展开看两边的原文，也可以导出为文本，不要只给一个「冲突」的标签。
合并结果里保留一个隐藏的原始版本，方便回退到合并之前的任意一边。
