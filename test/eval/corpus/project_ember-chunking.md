# 灰烬笔记

原先把整篇内容当成一个单位去比对，结果只要篇幅够长，什么问句都能沾上一点边。
后来改成先切成小片、再按片比对，最后只把最好的一片归并回整篇。
这样做的直接效果是篇幅不再自带优势：短的一篇只要说得准，就能排在前面。
代价是片与片的边界会丢一点上下文，所以片不能切得太碎，也不能切得太长。

这套取舍我试了三轮参数才稳定下来，最后记在配置注释里，不写进文档。
片长定在「一段话说得完」的量级，比它短的内容往上并，比它长的按结构切开。
之所以不做成可调项，是因为它一旦可调，每个调用方都会去调，最后没有共同口径。
参数稳定的标志是：换一份新语料，排名顺序不再剧烈变化，只是局部换位。
换语料时要重跑一遍对照，别只凭印象判断排名到底变了没有。
