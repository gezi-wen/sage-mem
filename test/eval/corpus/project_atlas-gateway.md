# Atlas 对外网关

## 配置

对外网关按租户限流，单个租户每秒最多 120 个请求，超过的部分直接拒绝，不排队。
拒绝会带一个 Retry-After，单位是秒，取当前窗口的剩余长度。

## 失败处理

上游连不上记一次超时并换下一个后端；上游返回错误则原样透传，不在网关侧改写。
换后端最多换两次，两次都失败才把请求判为失败。

## 限制

网关不缓存响应，重复请求会各自打到上游，缓存放在上游的读路径里。
每秒请求数是硬限制，改它要同时改租户侧的配额表，否则两边对不上。
网关的超时按单个请求计，一旦超时就断开连接，不做服务端重试。
限流窗口固定为一秒，窗口边界不随请求到达时间滑动。
网关的并发上限是六十个连接，超出之后新连接会被拒绝。
换后端的次数与租户的配额互不占用，两者分开计数。
